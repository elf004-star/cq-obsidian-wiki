# 中华人民共和国宪法

## 摘要
- **定位**：国家根本法，1982 年 12 月 4 日第五届全国人大第五次会议通过，经 1988、1993、1999、2004、2018 五次修正，**具有最高法律效力**。
- **结构**：序言 + 4 章（总纲 32 条 / 公民基本权利和义务 24 条 / 国家机构 / 国旗国歌国徽首都），共 143 条。
- **核心条款**：第一条国体（[[state-nature-guoti]]）、第二条政体、第三条民主集中制、第三十三条平等与人权保障。
- **效力**：一切法律、行政法规、地方性法规不得与宪法相抵触；任何组织或个人不得有超越宪法法律的特权。
- **实施机制**：全国人大及其常委会监督宪法实施（第六十二、六十七条）；2018 年设立宪法宣誓制度（第二十七条第三款）。

## 一、根本法地位

> 本宪法以法律的形式确认了中国各族人民奋斗的成果，规定了国家的根本制度和根本任务，是国家的根本法，**具有最高的法律效力**。（序言）

- 一切**法律、行政法规和地方性法规**都不得同宪法相抵触
- 任何组织或者个人都不得有超越宪法和法律的特权
- 宪法是制定其他一切法律的依据

### 要点
- 最高效力不是修辞，而是有具体规范后果：下位法抵触即无效。
- 中国宪法的实施监督权由全国人大及其常委会行使，无独立的违宪审查法院。

## 二、章节结构

| 章节 | 内容概要 |
|------|----------|
| 序言 | 历史定位、指导思想、根本任务、基本制度、对外政策 |
| 第一章 总纲 | 国体、政体、经济制度、民族政策、法治建设 |
| 第二章 公民的基本权利和义务 | 政治权利、人身自由、社会经济权利、公民义务 |
| 第三章 国家机构 | 全国人大、国家主席、国务院、军委、监察委、法院、检察院、地方国家机关 |
| 第四章 国旗、国歌、国徽、首都 | 象征性规定 |

### 要点
- 第二章在第三章之前，是 1982 年宪法的刻意安排：权利先于机构。
- 序言虽在体例上不属正文，但含「实质上即无产阶级专政」等定性条款，具规范意义。

## 三、公民基本权利（重要条款）

| 条款 | 权利内容 |
|------|----------|
| 第三十三条 | 法律面前一律平等；国家尊重和保障人权 |
| 第三十五条 | 言论、出版、集会、结社、游行、示威的自由 |
| 第三十六条 | 宗教信仰自由 |
| 第三十七条 | 人身自由不受侵犯 |
| 第三十八条 | 人格尊严不受侵犯 |
| 第三十九条 | 住宅不受侵犯 |
| 第四十条 | 通信自由和通信秘密受保护 |
| 第四十五条 | 获得物质帮助的权利 |

详见 [[citizens-basic-rights]]。

### 要点
- 第三十三条第三款「国家尊重和保障人权」为 2004 年修正案新增。
- 权利条款的行使受第五十一条限制：不得损害国家的、社会的、集体的利益和其他公民的合法自由和权利。

## 四、宪法修正历程

| 年份 | 主要修正内容 |
|------|-------------|
| 1988年 | 允许私营经济存在；土地使用权依法转让 |
| 1993年 | 社会主义市场经济；多党合作和政治协商制度入宪；县级人大任期改五年 |
| 1999年 | 邓小平理论入宪；依法治国、建设社会主义法治国家 |
| 2004年 | 「三个代表」重要思想；私有财产保护；人权入宪；戒严改紧急状态 |
| 2018年 | 习近平新时代中国特色社会主义思想；**党的领导写入第一条第二款**；监察委员会入宪；宪法宣誓制度；国家主席任期规定调整 |

### 要点
- 2018 年修正案最实质的变化是把「中国共产党领导是中国特色社会主义最本质的特征」写进**第一条**，使党的领导与国体同条。
- 同年增写监察委员会一节（第三章第七节），重构了国家机构体系。
